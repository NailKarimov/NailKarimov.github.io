How every project is built

A system I can look inside

Most suites test a service written for them or a private copy in Docker, so the tests can check what was stored, move the clock and forge tokens.

Proof that the tests work

Bugs are planted one at a time and every one must fail the suite. Known defects are pinned by tests that turn red the day they are fixed.

Reports someone can read

Allure reports on Pages, a test plan and summary report per repository, bug reports in Issues, and an interactive guide for every tool.
