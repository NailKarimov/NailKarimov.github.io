# nailkarimov.github.io

The front page of my test automation portfolio: https://nailkarimov.github.io/

One static page (`index.html`, no build step) that links to the 14 repositories, their published reports and
guides, and the [defect board](https://github.com/users/NailKarimov/projects/2). GitHub Pages serves it from
`main`; `.nojekyll` turns off the Jekyll build.

Numbers on the page come from the latest CI runs of each repository; update them when a repository's README changes.
